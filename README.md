# RIFTWEAVE: Shards of Aether

Tactical match roguelike built as a standalone project.

## Playable systems
- 7x7 match board with swaps, cascades and tactical tile identities.
- Three visible combat characters with attack, cast, hit and defeat animations.
- Character energy and ultimate abilities.
- Enemy turns, shields, bosses and scaling encounters.
- Roguelike relic choices that change combat rules and synergies.
- Reactive procedural Web Audio, particles, impact feedback and camera shake.
- Animated title screen, pause/settings, squad codex and run-end flow.
- Local settings and meta progression persistence.
- Responsive desktop/mobile presentation and reduced-motion option.

## Local run
Serve the repository with any static web server and open `index.html`.

## Deployment
The `Deploy RIFTWEAVE` GitHub Actions workflow validates `game.js` and publishes the repository to GitHub Pages.
