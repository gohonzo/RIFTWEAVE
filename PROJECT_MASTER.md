# RIFTWEAVE — Project Master

RIFTWEAVE: Shards of Aether is the standalone project in this repository.

## Non-negotiable direction
- Tactical 7x7 match roguelike with builds, relics, cascades, bosses and meta progression.
- Kael, Lyra and Nyx must be visible combat units with idle/attack/cast/hurt/KO feedback.
- No visible placeholder geometry for characters, enemies or board pieces.
- Tiles must remain square, readable and proportionally consistent.
- Desktop, tablet and mobile layouts are responsive layouts, not a shrunken fixed canvas.
- Fullscreen and Fit-to-screen controls remain available.
- Visual feedback includes trails, particles, impact flashes, cascades, combo feedback and configurable camera shake.
- Menus are functional game menus: Continue, New Run, Heroes, Relics, Codex, Achievements and Settings.
- Do not reintroduce an "Art" gallery as a primary game menu.
- Keep this repository independent from STARLOOM and all other projects.

## Current production build
The deployed Pages build is reconstructed from .bundle/part_*.b64 by GitHub Actions, integrity-checked and JavaScript-validated before deployment.
